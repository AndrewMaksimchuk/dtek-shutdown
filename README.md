# dtek-shutdowns

Go to website [DTEK](https://www.dtek-krem.com.ua/ua/shutdowns) and set home address and get screenshot of schedule shutdowns.

Before run appliaction, you must file ./textOfInputFields.template.json* rename to ./textOfInputFields.json and write correct address for each field in this file.



To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

To type check:

```bash
bun check
```

Run `bun fmt` to format the code.

This project was created using `bun init` in bun v1.4.4. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
